## 📌 Project Overview

**FreshBasket** is a modern online grocery shopping web application inspired by real-world grocery delivery platforms. It provides users with a convenient way to explore grocery products, manage shopping carts, create wishlists and complete their shopping experience through an interactive interface.

The platform also introduces smart shopping features such as Budget Guardian, Smart Basket Planner and Freshness & Waste Saver to encourage better shopping decisions, budget management and reduced food waste.

This project is developed as an academic project to demonstrate modern frontend development concepts, component-based architecture and interactive web application design.

## 🎯 Project Objectives

- To develop a user-friendly online grocery shopping platform.
- To simplify product browsing and shopping cart management.
- To provide an interactive and responsive shopping experience.
- To introduce smart tools for budget-friendly shopping.
- To help users plan grocery purchases efficiently.
- To promote awareness about food freshness and food waste reduction.

## ⚙️ Installation and Setup

Follow these steps to run FreshBasket on your local machine.

### Prerequisites

Make sure you have installed:

- Node.js (LTS version recommended)
- npm
- Git

### Step 1: Clone the Repository

```bash
git clone https://github.com/shivam19228/FreshBasket.git
```

### Step 2: Navigate to Project Directory

```bash
cd FreshBasket
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start Development Server

```bash
npm run dev
```

### Step 5: Open in Browser

Visit the following URL:

```text
http://localhost:5173
```
